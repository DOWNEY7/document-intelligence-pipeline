# Security Policy

## Supported Versions

We actively maintain and patch security vulnerabilities on the latest release of the Document Intelligence Pipeline.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of the Document Intelligence Pipeline seriously. If you discover a potential vulnerability or security flaw, please do **NOT** open a public issue.

Instead, please report security disclosures privately by emailing:
**downey07@protonmail.com**

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof-of-concept (PoC).
- Any proposed remediation or patches if available.

### Vulnerability Response SLA
- **Initial Acknowledgement**: Within 48 hours.
- **Triage & Validation**: Within 5 business days.
- **Fix & Disclosure Advisory**: Coordinated responsibly upon release of the fix.
